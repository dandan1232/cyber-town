# 分阶段验收清单

勾选表示实际完成验证；未勾选项目不得理解为已通过。真实模型和部署需以最终执行记录为准。

## 阶段一：文档

- [ ] README 说明启动方式、模式区别及存档范围。
- [ ] 需求覆盖移动、角色、对话、记忆、关系、背景状态和日志。
- [ ] 架构明确浏览器与服务端职责、无云存档和无向量库的边界。

## 阶段二：办公室

- [ ] 场景与三个角色正常显示，无控制台异常。
- [ ] WASD/方向键可以移动，家具和边界碰撞有效。
- [ ] 靠近每位 NPC 后可按 E 开始对应对话。
- [ ] 输入含 WASD/E 的文字不引起角色移动。
- [ ] 手机尺寸下触控移动、场景和聊天输入均可用。
- [ ] 背景状态可见，交互按钮具有可见键盘焦点。

## 阶段三：对话、记忆与关系

- [ ] 无密钥时状态接口和页面明确显示演示模式。
- [ ] 三位角色回复具有职业差异，历史相互隔离。
- [ ] 告知姓名或喜好后可以回忆；其他角色不能自动得知。
- [ ] 友好与不友好消息产生合适变化，分数不超出 0–100。
- [ ] 刷新后历史与关系恢复；损坏存档不导致页面无法进入。
- [ ] 日志可见、可以导出，导出文件能读取。
- [ ] 等待回复时不能重复发送，失败后可重试。

## 阶段四：测试与构建

```bash
npm test
npm run build
```

- [ ] 自动测试全部通过，记录实际数量和结果。
- [ ] 生产构建成功，产物不包含模型密钥。
- [ ] 非法角色、空消息、过长消息、错误结构被拒绝。
- [ ] 模型异常、超时或错误结构不伪装为成功对话。
- [ ] 模拟请求验证角色设定、历史和记忆正确传入模型。
- [ ] 配置口令后，未授权请求不能调用受保护接口。
